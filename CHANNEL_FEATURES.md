# Додаткові можливості інформаційного каналу

Усі кнопки керування залишаються на нижній клавіатурі бота. Повний пакет також містить звернення, замовлення, налаштування, статистику й попередній редактор публікацій.

## Контроль джерел

Коли автопублікацію ввімкнено, бот перевіряє джерела приблизно щохвилини. Якщо акаунт відключений, втратив доступ або читання не підтверджує роботу понад 3 хвилини, адміністратори отримують сповіщення. Для джерел через бота перевіряється доступ бота до каналу. Відновлення також супроводжується повідомленням. Повторні перевірки одного збою не створюють однакових повідомлень; невідправлені сповіщення зберігаються до відновлення зв'язку.

Картка джерела показує стан, час перевірки та час останнього отриманого допису за Києвом. Тиша у каналі сама по собі не вважається помилкою: відсутність новин не означає збій. Навмисне вимкнення читання не створює тривожних сповіщень. Якщо хост вимкнений або сам бот повністю зупинився, надіслати попередження він зможе лише після відновлення; для контролю вимкненого ПК потрібен зовнішній моніторинг.

## Джерело й час новини

**Канали → Джерело й час** вмикає або вимикає позначку для майбутніх дописів із джерел. Початково вона ввімкнена. Вказується назва джерела й час його допису за Києвом, а не час події. Для публічного джерела назва є посиланням на оригінал. Для приватного показується назва без публічного посилання.

Позначка зберігається разом із чернеткою, тому зміна налаштування впливає на наступні отримані дописи. Ручні дописи не отримують вигаданого джерела. Обмеження довжини тексту та підписів враховують позначку; якщо ліміт перевищений, допис потребує редагування. Для повідомлень, які Telegram дозволяє лише переслати без редагування, позначка не додається.

## Шаблони

**Публікації → Шаблони повідомлень**:

- 🚨 Повітряна тривога.
- 🟢 Відбій повітряної тривоги.
- 💡 Інформація про відключення.
- 📢 Оголошення.

Виберіть шаблон і надішліть перевірені відомості одним текстом. Бот додасть заголовок і збереже чернетку. Територію, час події й джерело вказує редактор. Далі можна додати фото, відео, кнопки й підписи через звичайний редактор, переглянути результат і підтвердити публікацію. Шаблон сам не підтверджує достовірність тривоги чи відбою й нічого автоматично не публікує.

## Уточнення до новини

Відкрийте опублікований ботом допис → **Додати уточнення**. Надішліть текст або медіа, перегляньте й підтвердьте публікацію. Для модератора потрібне погодження адміністратора.

Уточнення зберігається окремим дописом, має кнопку переходу до оригіналу в боті й після публікації надсилається **відповіддю на оригінальне повідомлення в тому самому каналі**. У картці оригіналу з'являється список пов'язаних уточнень зі статусами. Фото, відео й альбоми також можуть бути уточненнями.

Якщо оригінал видалений із Telegram, надсилання відповіді може завершитися помилкою — автоматичної публікації без прив'язки не буде. Для зміни самого тексту оригіналу залишається окрема кнопка **Виправити в каналі**.
